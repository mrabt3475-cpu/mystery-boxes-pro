# Mystery Boxes Pro

Professional mystery boxes platform with Islamic compliance.

## Features

- Multi-provider system (Kingdomlikes, G2A, CJdropshipping)
- Islamic-compliant operations (no interest/gambling)
- Provably fair RNG
- Referral system with tiered commissions
- Developer API for custom integrations
- Dynamic pricing based on demand

## Setup

```bash
npm install
cp .env.example .env
npm run seed
npm start
```

## API Endpoints

- `/api/v1/auth` - Authentication
- `/api/v1/boxes` - Box operations
- `/api/v1/wallet` - Wallet management
- `/api/v1/referral` - Referral system
- `/api/v1/admin` - Admin dashboard
